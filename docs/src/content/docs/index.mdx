Build native Wayland desktop surfaces with HTML, CSS, and JavaScript. YAWSF runs a local
authenticated host API beside your web application, and your shell chooses which pages to expose as
native surfaces.

<CardGrid stagger>
	<Card title="Layer-shell windows" icon="add-document">
		Create bars, panels, backgrounds, overlays, and other compositor-managed surfaces.
	</Card>
	<Card title="Session locking" icon="setting">
		Render a web page on every compositor-provided session-lock surface.
	</Card>
	<Card title="Web app supervision" icon="rocket">
		Let YAWSF start, monitor, and gracefully stop your shell backend.
	</Card>
</CardGrid>
